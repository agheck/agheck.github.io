Mandelbrot Set Acceleration

The Mandelbrot set is a renowned fractal defined by an iterative equation involving complex numbers. This project leverages hardware acceleration for generating Mandelbrot set images, which is a task that proves to be computationally intensive due to the number of pixels and the high number of iterations required to calculate each pixel in the set. Throughout this project, FPGAs and the Vivado HLS toolchain were utilized to design a highly parallelized architecture that significantly enhances the efficiency of Mandelbrot set computations.

Optimizations include choosing a good data type for the calculations, implementing tiling to compute multiple pixels in parallel, and using HLS pragmas to further improve efficiency.
